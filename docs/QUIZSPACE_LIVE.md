# QuizSpace Live QR Game

Додано режим Live Quiz у стилі Kahoot.

## Можливості
- створення Live-гри з курсу;
- питання з 2–6 варіантами відповідей;
- правильна відповідь для кожного питання;
- індивідуальний таймер кожного питання;
- картинка за прямим URL з інтернету;
- автоматична генерація 6-значного PIN;
- QR-код для входу з телефона;
- гравці заходять без облікового запису;
- вибір аватара-фігурки;
- live-лобі та список гравців;
- автоматичний перехід після завершення таймера;
- бали за правильність і швидкість відповіді;
- екран ведучого;
- екран учасника;
- фінальний результат;
- збереження створених Live-ігор у курсі.

## Як запустити
1. Замініть файли вашого `quiz` файлами з цього архіву.
2. Увійдіть як учитель/адмін і відкрийте курс.
3. Натисніть `🎮 Live QR-гра`.
4. Створіть питання.
5. Натисніть `🚀 Створити гру`.
6. На екрані ведучого буде PIN та QR-код.
7. Учні сканують QR-код, вводять ім'я, обирають фігурку та відповідають.

## Важливо
QR-код у поточній версії генерується через QuickChart URL, тому для відображення QR на екрані ведучого потрібен доступ до Інтернету. Сам QuizSpace Live працює через ваш PHP/MySQL сервер.

Таблиці Live автоматично створюються через `ensure_live_tables()`. Також є ручна міграція `docs/migration_live_quiz.sql`.
