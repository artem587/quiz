# QuizSpace — оптимізація Live QR-гри

## Зміни
- Додано повне редагування збережених Live-квізів.
- Додано видалення Live-квізів разом із їхніми сесіями, гравцями та відповідями.
- Редагування заборонене під час активної Live-сесії, щоб не пошкодити поточну гру.
- Екран гравця переведено в окремий повноекранний режим без навігації платформи.
- Відповіді на екрані гравця — великі кольорові блоки 2×2, з текстом відповіді та фігурою.
- На малих екранах блоки автоматично переходять у вертикальний формат.
- QR-код і PIN залишаються прив'язаними до конкретного запуску, а не до збереженого квізу.
- Додано кнопки редагування/видалення в менеджері Live-квізу.
- Оновлено CSS cache-busting до v64.

## Перевірки
- Усі PHP-файли пройшли `php -l`.
- Inline JavaScript у Live create/host/player перевірено через Node.js syntax check.
